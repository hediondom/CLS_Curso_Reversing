# Teorias_Numeradas (colección de tutoriales)

| Campo | Dato |
|---|---|
| **Autor / organización** | Múltiples autores de la comunidad CLS |
| **Tipo** | 2.023 contenedores (.rar, .zip, .7z) organizados por número, ~3,5 GB |
| **Ruta local** | `CLS_fuentes_externas/github/apuromafo_Crackslatinos/Teorias_Numeradas` |
| **Etapa** | 4 (referencia); gran parte fuera del recorrido |
| **Nivel** | Variable |
| **Prerrequisitos** | Variable |
| **Duración** | Desconocida por archivo; el CSV tiene tamaños, no duraciones. |
| **Estado** | Clasificado por título: 2.017 tutoriales separados en educativos vs cracking (ver índice) |

## Qué se revisó

Se clasificaron los 2.017 títulos por categoría: ver [Teorias_Numeradas clasificadas](../teorias.html). ~1.591 (79%) apuntan a cracking de software comercial; ~426 son candidatos educativos. No se abrió ningún contenedor (varios con contraseña).

## Contenido explicado

Tutoriales de todos los niveles: teoría básica, assembler, .NET/Java/VB, herramientas, crackmes, criptografía, y gran parte sobre cracking/unpacking/seriales de software comercial.

## Utilidad para el curso

Índice para localizar un tema; el filtrado por título ayuda a descartar el ~79% de cracking comercial. No es un curso secuencial.

## Limitaciones y antigüedad

Clasificación **por título, no por contenido**: un título no demuestra lo que enseña. No se abrió ningún .zip. No presentar como leído.
